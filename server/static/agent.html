Agentic commerce · backed by PayPal

One AI agent. Every way to pay a website.

Give your agent a task and a spending mandate. It reads the site's offer catalog, then crawls with a refundable deposit, buys pay-per-access media, subscribes, and shops, all through PayPal. The site prices every offer and verifies every payment, and you approve anything large or recurring.

How it works

  1. 1
    The site publishes its offersA machine-readable catalog, and an HTTP 402 on paid content that says how to pay. Also available to any AI assistant as an MCP storefront.
  2. 2
    You set a mandateA budget, the payment types allowed, and an amount above which the agent must ask you. Recurring charges always ask.
  3. 3
    The agent pays through PayPalRefundable crawl deposits, pay-per-access, subscriptions, and product orders, each on the PayPal API built for it.
  4. 4
    The site verifies with PayPalNothing unlocks or ships until PayPal confirms the payment. Webhooks keep orders and subscriptions in sync; the publisher sees every payment in the console.
