# CrawlerTrust Runtime Storage

This directory stores runtime state and append-only audit logs generated by the CrawlerTrust server:

- `audit.jsonl`: Append-only JSON Lines log recording security-relevant events (challenges, deposits, payment verifications, policy acceptances, token issuances, content requests, policy violations, session completions, refund outcomes, and forfeiture decisions).
- `payments_db.json`: Atomic JSON snapshot of challenges and deposits (including separated `payment_status`, `policy_decision`, and `refund_status` fields).
- `sessions_db.json`: Atomic JSON snapshot of crawler sessions (storing only SHA-256 hashes of bearer tokens, never raw tokens).

## Important Limitations

1. **Single-Process Demo Persistence**: Snapshots are written atomically using temporary files and `os.replace` guarded by process-local `asyncio.Lock` instances. This is designed for a single-process local demonstration and is **not** a distributed locking or multi-worker transactional database.
2. **Audit Log Integrity**: `audit.jsonl` is opened in append mode (`"a"`) and never rewritten by the application, but a local file on disk is not cryptographically tamper-proof against a privileged host user.
3. **Git Exclusion**: Runtime `.json`, `.jsonl`, and `.tmp` files in this folder are excluded via `.gitignore` so local test runs and sensitive runtime states are never committed.
