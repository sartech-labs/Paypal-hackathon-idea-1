SARA — End-to-End Request Lifecycle

Deposit-Backed Accountability Flow for AI Crawlers

sequenceDiagram
    autonumber
    actor Crawler as AI Crawler Client
    participant Gateway as FastAPI Gateway (:8000)
    participant PayPal as PayPal Sandbox / Mock Provider
    participant Audit as Audit Log (storage/audit.jsonl)

    Crawler->>Gateway: 1. GET /gateway/news (No Bearer Token)
    Gateway->>Audit: Log CHALLENGE_ISSUED
    Gateway-->>Crawler: HTTP 402 Payment Required (challenge_id, deposit: $0.01 USD)

    Crawler->>Gateway: 2. GET /policies & GET /robots.txt
    Gateway-->>Crawler: 200 OK (Allowed paths, Disallowed paths, Rate limits)

    Crawler->>Gateway: 3. POST /deposits/create (challenge_id, crawler_id)
    Gateway->>PayPal: Create Order ($0.01 USD, PayPal-Request-Id)
    PayPal-->>Gateway: Order ID + Approval URL
    Gateway->>Audit: Log DEPOSIT_INITIATED
    Gateway-->>Crawler: 201 Created (deposit_id, provider_order_id, approval_url)

    Note over Crawler,PayPal: In PayPal Sandbox mode, payer approves order in browser

    PayPal-->>Crawler: Redirect browser to return_url with token (order ID)
    Crawler->>Gateway: 4. GET /deposits/paypal/return?deposit_id=...&token=...
    Gateway->>Gateway: Match returned order ID to persisted deposit
    Gateway->>PayPal: Capture with stable request ID; verify COMPLETED, amount, currency, capture_id
    PayPal-->>Gateway: Capture response
    Gateway->>Audit: Log PAYMENT_VERIFIED only after backend verification
    Gateway-->>Crawler: 200 OK (payment_status=CAPTURED)
    PayPal-->>Crawler: On cancel, redirect to cancel_url
    Crawler->>Gateway: GET /deposits/paypal/cancel?deposit_id=...&token=...
    Gateway-->>Crawler: Cancellation reported; deposit remains uncaptured

    Crawler->>Gateway: 5. POST /sessions/accept-policy (agree_to_terms=true, v1.0)
    Gateway->>Audit: Log POLICY_ACCEPTED & SESSION_ISSUED (SHA-256 hash stored)
    Gateway-->>Crawler: 201 Created (One-time raw Bearer token)

    loop Crawling Loop
        Crawler->>Gateway: 6. GET /gateway/news (Authorization: Bearer token)
        alt Authorized (Within rate limit & allowed path)
            Gateway->>Audit: Log GATEWAY_ACCESS_ALLOWED
            Gateway-->>Crawler: 200 OK HTML Content
        else Violation (Disallowed path / Rate limit exceeded)
            Gateway->>Audit: Log POLICY_VIOLATION (disqualifying=true/false)
            Gateway-->>Crawler: 403 Forbidden / 429 Too Many Requests
        end
    end

    Crawler->>Gateway: 7. POST /sessions/complete (Authorization: Bearer token)
    Gateway->>Gateway: Evaluate session history for disqualifying violations
    alt Compliant Session (0 disqualifying violations)
        Gateway->>PayPal: POST /v2/payments/captures/{id}/refund
        PayPal-->>Gateway: Refund COMPLETED (provider_refund_id)
        Gateway->>Audit: Log DEPOSIT_REFUNDED
        Gateway-->>Crawler: 200 OK (deposit_state=REFUNDED, refund_status=REFUNDED)
    else Violating Session (Disqualified)
        Gateway->>Audit: Log DEPOSIT_FORFEITED
        Gateway-->>Crawler: 200 OK (deposit_state=FORFEITED, policy_decision=FORFEITED_BY_POLICY)
    end
